# Tanpura · 弦外之境

无需登录的十二调 Tanpura 单页播放器，使用 React 和 Vite。源码位于 `src/`，静态资源位于 `public/`，`dist/` 为可重新生成的构建产物。

开发：`pnpm dev`，然后打开终端显示的本地地址。

验证：`pnpm test`。构建：`pnpm build`。预览构建：`pnpm preview`。

各调直接播放完整录音，不做升降调或变速；频率为标称值，并非实测校准。使用媒体元素流式播放，避免解码整段 PCM；暂停和快速切调会让旧异步请求失效。

浏览器首次播放需要用户点击。线上使用每调完整约 25 分钟录音，以 96 kbps MP3 发布，播完循环；原始 320 kbps 文件保存在 `outputs//`。可运行 `node scripts/prepare-audio.mjs` 重新生成发布文件，需本机安装 FFmpeg。琴弦和共鸣光环由实际音频能量驱动，暂停、静音和系统减少动态效果设置均会停止振动。

系统休眠、手机锁屏或浏览器冻结页面可能中断播放。
