# Tanpura · 弦外之境

用于听音训练（Ear Training）的十二调持续音播放器。以持续主音为参照，叠加合成器音符，练习辨听音高与音程。无需登录，支持中文和 English。

## 使用

1. 选择调性，点击播放。每个调都有约 25 分钟的完整录音，播完自动循环。
2. 拖动音量条调整音量；点击暂停停止播放。
3. 使用合成器叠加音符，聆听它与主音的音程关系：选择音域，按住琴键发声，或切换到「点击持续」。合成器音量可独立调节。

合成器也支持电脑键盘：Z–M 为低音区，Q–U 为高音区，I 为最高音。

页面默认跟随浏览器语言，可手动切换。建议佩戴耳机；休眠、手机锁屏或浏览器冻结页面可能中断播放。
