# Tanpura · 弦外之境

无需登录的十二调 Tanpura 单页播放器，使用 React 和 Vite。源码位于 `src/`，静态资源位于 `public/`，`dist/` 为可重新生成的构建产物。

开发：`pnpm dev`，然后打开终端显示的本地地址。

验证：`pnpm test`。构建：`pnpm build`。预览构建：`pnpm preview`。

各调直接播放对应录音，不做升降调或变速；频率为标称值，并非实测校准。音频按需下载，最多缓存最近两个解码缓冲区；暂停和快速切调会让旧异步请求失效。

浏览器首次播放需要用户点击。线上使用每调录音第 60–120 秒的一分钟片段，首尾交叉淡化。原始十二份文件保存在 `outputs//`，可运行 `node scripts/prepare-audio.mjs` 重新生成公开片段，需本机安装 FFmpeg。完整原件不进入发布包。

系统休眠、手机锁屏或浏览器冻结页面可能中断播放。
